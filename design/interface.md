# Endless Adventure 设计：界面（方向）

本文件是 [DESIGN.md](../DESIGN.md) 的 §8，章节编号沿用总文档，文中“§X.Y”跨文件通用（各章所在文件见 DESIGN 的模块索引）。术语见 DESIGN 术语表，计划与实现现状见 DESIGN §2。

## 8. 界面（方向）

- 窗口按 Windows Terminal 最大化 209×51 设计，不做自适应；画布占满窗口，状态消息与按键提示画在底边框上。
- 输入采用 JLine（讲师不建议外部库但未禁止；提交时附依赖与运行说明），raw 模式读取按键与终端内鼠标（Windows Terminal）；文字输入也在画布上完成，不使用行输入。不改为窗口 GUI（2026-10-13 确认）。
- 交互通则（2026-10-15 确认，10-17 修订）：所有功能都必须能用鼠标点到，并至少能用直接按键或方向键选择之一完成；只靠快捷键的功能须有可见按钮，按钮不标快捷键，快捷键统一列在底部提示中。命令型条目悬停与方向键共用一个焦点、单击直接执行；对象型条目（存档卡片）悬停不改变选中、单击选中，再由按钮执行。焦点统一用金色前景（行首 `▌` 与金色文字，或金色边框），不用背景色块。一个画面有多个可操作区域时分模式处理，Esc 先退出当前模式。角色、日志、NPC 等补充信息不常驻画面，由玩家主动调出覆盖层查看。
- 图片用半块字符 ▀ 加 RGB 前景／背景，一格表达上下两个色点；文字压在图片上的格子会失去细节，此代价已接受。
- **战斗画面（2026-10-25 定初版，10-27 按实现修订；参考 `references/combat_screen_baseline.png`）。** 俯瞰网格加像素小人，现代简约：无边框的填充面板（比背景略亮），不画屏幕外框与底部提示；先预览再确认。
  - **布局。** 左栏 3–40 列、地图 44–163 列、右栏 167–204 列；面板占第 2–49 行，每栏上下两块（上 15 行，空一行，下 32 行）。地图 10×7 格（一格 12×12 色点＝12×6 字符）在第 5–46 行，左上角压一行地点与轮次；第 48–49 行是地图下方居中的先攻条。战斗中不放工具栏（开背包或角色界面会丢掉这场战斗；以后如需查看做成只读覆盖层）。
  - **信息栏。** 左上是玩家，右上是敌人，同一布局：大号小人（26 色点高）、名字、等级、HP 数字与血条、护甲（防御中写成“护甲 + 防御加值”）、速度；AP 圆点与剩余移动格数只在当前行动者的栏里显示。敌人的定位与行为模式是内部机制，不显示。
  - **行动栏（左下）。** 行按钮，按顺序编号，每个占 4 行：名称、右侧 AP 圆点、下一行暗色说明（伤害、防御加值、闪避率；不可用时写原因）。列出攻击、有副手武器时的副手攻击、防御（有盾时为 Shield Guard）、能闪避且可用时的闪避、撤离；底部 END TURN 与 Confirm，选中可用的行动后 Confirm 才可点。结束回合不提示下一个行动者，看先攻条。攻击与移动既可从行动栏发起，也可直接点地图（计划，3.3）。
  - **战报（右下）。** 计划：显示事件文字；指向可执行的目标时，这一块换成预览（伤害、命中率、AP 与路线），确认后执行。
  - **先攻条。** 每个活着的单位一段：名字、`HP / 最大HP`、下一行短血条；当前行动者底色更亮、左侧金色 `▌`。设计待改。
  - **地图与素材。** 格线很淡；单位脚下一条 HP 细条。人物与树按行从上到下绘制，下一行盖住上一行，第一行的树可以伸出地图顶边。顶光接触阴影，宽度取素材底部最宽处，不做投射阴影。小人由立绘直接缩成 17 色点高、透明度只有开关、不加描边；树侧视约 20 色点高。地面一张 120×84 色点的图（`assets/grounds`）。
- 冒险画面：v0 为单列阅读布局（顶栏、场景图区、叙述、选项与自由输入），场景图区先放占位。之后走视觉小说方向（参考 `references/adventure-overlay-209x51.png`）：场景＋当前 NPC 半身像，叙述中 NPC 名字与台词高亮，点击名字查看 NPC 信息。常用素材预先生成并转换；仅资产库缺失时在后台实时生图，未就绪显示占位，不阻塞剧情。
- **物品格与容器（2026-10-21 确认，10-22 修订）。** 所有物品列表用同一个格子组件，按以后会有图标来设计。每件物品占一个独立方框，方框之间留空、不共用边框（横向空 3 列、纵向空 1 行，字符约为两倍高，看起来等距）；方框正好装下一个图标：12×12 色点即 12×6 字符（与战斗网格一格同尺寸），连边框 14×8。容量内的空位画成更暗的空方框。格子里不另写物品名，与其他游戏的背包一致，物品名在详情区显示；图标未就绪时由物品名（按品质上色、居中折行）代替图标，后台生图未完成时也用这个占位。已装备的物品在方框上边框标 `EQUIPPED`，以后的堆叠数量也标在方框边上。容器只规定列数、行数和标签页（筛选），点击后的行为由所在画面决定；装备位是同尺寸的单个方框。详情区把图标放大两倍显示。
- **创角起始装备（2026-10-21 确认）。** 创角第 4 步，位于通用技能之后、确认之前，分三栏：
  - **左栏：角色（宽 68，2026-10-24 改为纸娃娃）。** 名字、等级、HP；七项主属性排成一行（缩写在上、数值在下）；三项战斗技能一行；下面是纸娃娃：全身立绘站在两列装备位之间，装备位按身体部位摆放（主手、护甲在左，副手在右；另留三个位置给以后的装备位，未启用的不显示）。装备位的名称居中写在上边框，它在战斗中提供的数值居中写在下边框：主手 `ATK`、护甲 `ARMOR`，副手是盾时 `GUARD`、是武器时 `ATK`；持双手武器时副手位显示同一把武器并标 `TWO-HANDED`。速度、闪避与通用技能不在这一栏（见角色界面）。立绘每个形象一张，最大 32×62 像素、透明背景，不随装备变化（2026-10-24 确认）：装备只修正数值，外观由两侧装备位的图标表现；AI 生成的图无法按同一身体模板逐像素对齐，底图加护甲图层的分层换装做不到，每件装备一张立绘则会随形象与种族组合爆炸。以后可按护甲类型（轻、中、重）为每个形象各出一版（方向）。玩家的头像尚未存档，界面暂时读固定 ID `player`（默认立绘为兜帽旅行者）。背包、创角第 4 步与第 5 步、角色界面共用这一栏。
  - **中栏：起始装备（宽 77）。** 4×4 格（2026-10-24 由 5×4 改回，为左栏腾出宽度），标签页 MAIN HAND／ARMOR／OFF HAND 各列出能装进该位置的普通品质物品。点击格子装进当前标签对应的位置，再点已装备的那件卸下；点左栏的装备位切换到对应标签，当前标签的装备位用天蓝框。
  - **右栏：详情（宽 54）。** 显示悬停的物品，没有悬停时显示当前标签已装备的那件；描述跟在特性后面，用分隔线隔开。底部固定位置的 IF EQUIPPED 只列会变的派生数值，如 `Attack 14 (+3)`，变好用绿色、变差用红色，并列出会被换下的装备。BACK／NEXT 在详情下方，主手与护甲都装上之前 NEXT 不可用。
  - **键盘。** 方向键只在格子内移动（到边停住，不绕回）；装备位用 TAB／Shift+TAB 或点击切换，不占键盘焦点；E 装备或卸下，ENTER 下一步，ESC 返回。
- **背包（2026-10-22 确认）。** 从冒险界面工具栏的 Inventory 或 I 键打开，ESC、I 或 CLOSE 关闭。三栏同创角第 4 步：左栏角色（真实玩家），中栏 BACKPACK 4×4 格，右栏详情加 CLOSE。背包格子与身上的装备位都是命令型条目：悬停与键盘共用焦点，单击直接执行；TAB／Shift+TAB 在背包与身上两个区域间切换，方向键在区域内移动，E 与单击相同。单击背包里的装备按 §7.1 默认规则装上，换下的回到背包；单击身上的装备位卸回背包，空位只提示。背包里的装备显示按默认位置比较的 IF EQUIPPED，身上的不比较。装备后从背包移走、不标 E（格子背包＋纸娃娃的做法，参考《博德之门 3》；标 E 属于没有装备位的清单式背包）。暂不做分类标签、分页（超过 16 件时多出的不显示，加战利品时一并做）、拖拽；有使用、丢弃等多种操作的物品出现时，改为对象型（单击选中、按钮执行）。
- **角色界面（2026-10-24 确认）。** 从冒险界面工具栏的 Character 或 C 键打开，ESC、C 或 CLOSE 关闭。与背包像同一窗口的两个标签页：顶部居中的 CHARACTER／INVENTORY 标签可点击切换（当前页金色加下划线），角色界面按 I、背包按 C 也直接切换。左栏同背包；右边 DETAILS 列出左栏没有的数值：次要数值（速度、闪避、先攻、经验）与全部通用技能（未学的变暗），以后的背景、特质、特殊行动与升级加点也放在这里，不另做左栏标签页。创角第 5 步用同样的左栏与 DETAILS，右边是 READY? 与 CONFIRM。参考《暗黑破坏神 4》《博德之门 3》：装备界面只放换装相关的内容，其余在角色表。
- **建议特效：**静态人物配短暂的命中变色、伤害数字、斩击弧或光点轨迹，约 0.3–0.5 秒。机械结果只结算一次，动画跳过或失败不重复结算；播放期间暂停输入，不引入多线程。可参考 [JLine Display 差异更新](https://jline.org/docs/advanced/screen-clearing/#using-the-display-class)。
- **音频（v1，2026-10-24 加入）。** 用 JDK 自带的 `javax.sound.sampled` 播放 WAV，不加依赖；音乐压成 22kHz 单声道以控制体积。背景音乐按界面切换（主菜单、冒险、战斗），同一首不重启；背包、角色与存档界面不切换，从战斗打开背包时仍是战斗音乐。界面音效统一在输入处理处按输入种类触发（移动焦点、确认、返回），被拒绝的操作随警告与错误提示播放错误音，打字不出声。指向区域（战斗地图格子）的悬停与点击不出声，由所在界面在知道结果后播放。战斗音效按战斗事件播放：未命中、伤害全被吃掉、命中各一种，防御行动用格挡声；一串事件只放第一个有声音的，没有战斗声音的玩家行动放确认音。没有动画之前，界面音与战斗结果音几乎同时响，不易分辨；做命中特效时改为每个事件随动画放自己的声音（2026-10-31）。素材用 CC0 等可再分发的授权，来源写进 README。没有音频设备或文件缺失时静默跳过，不影响游戏。音量与开关是否做进设置待定。
- **顺序。** 创角起始装备 → 背包 → 角色界面 → 战斗界面 → 冒险界面的日志抽屉与 NPC 高亮。图片转字符格、后台生图与视觉小说冒险界面放到 v1 之后视进度而定。
