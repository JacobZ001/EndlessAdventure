# Endless Adventure 设计：界面（方向）

本文件是 [DESIGN.md](../DESIGN.md) 的 §8，章节编号沿用总文档，文中“§X.Y”跨文件通用（各章所在文件见 DESIGN 的模块索引）。术语见 DESIGN 术语表，计划与实现现状见 DESIGN §2。

## 8. 界面（方向）

- 窗口按 Windows Terminal 最大化 209×51 设计，不做自适应；画布占满窗口，状态消息与按键提示画在底边框上。
- 输入采用 JLine（讲师不建议外部库但未禁止；提交时附依赖与运行说明），raw 模式读取按键与终端内鼠标（Windows Terminal）；文字输入也在画布上完成，不使用行输入。不改为窗口 GUI（2026-10-13 确认）。
- 交互通则（2026-10-15 确认，10-17 修订）：所有功能都必须能用鼠标点到，并至少能用直接按键或方向键选择之一完成；只靠快捷键的功能须有可见按钮，按钮不标快捷键，快捷键统一列在底部提示中。命令型条目悬停与方向键共用一个焦点、单击直接执行；对象型条目（存档卡片）悬停不改变选中、单击选中，再由按钮执行。焦点统一用金色前景（行首 `▌` 与金色文字，或金色边框），不用背景色块。一个画面有多个可操作区域时分模式处理，Esc 先退出当前模式。角色、日志、NPC 等补充信息不常驻画面，由玩家主动调出覆盖层查看。
- 图片用半块字符 ▀ 加 RGB 前景／背景，一格表达上下两个色点；文字压在图片上的格子会失去细节，此代价已接受。
- 战斗画面为俯瞰网格＋Unicode 像素小人（参考 `references/combat-top-down-unicode-proportions-v2.png`），显示双方 HP、特殊行动可用性与敌人状态。小人比例偏写实，保留色调、关键特征与轮廓，可高出所在格；装饰高度不引入高度规则。一格 12×12 色点，对应 12×6 字符；地图素材需透明掩码，输出前与地面合成。**建议布局：**战场居左，右侧显示选中对象、行动预览、行动顺序与战报，底部为行动栏；先预览再确认。
- 冒险画面：v0 为单列阅读布局（顶栏、场景图区、叙述、选项与自由输入），场景图区先放占位。之后走视觉小说方向（参考 `references/adventure-overlay-209x51.png`）：场景＋当前 NPC 半身像，叙述中 NPC 名字与台词高亮，点击名字查看 NPC 信息。背包参考 `references/inventory-character-209x51.png`。常用素材预先生成并转换；仅资产库缺失时在后台实时生图，未就绪显示占位，不阻塞剧情。
- **物品格与容器（2026-10-21 确认，10-22 修订）。** 所有物品列表用同一个格子组件，按以后会有图标来设计。每件物品占一个独立方框，方框之间留空、不共用边框（横向空 3 列、纵向空 1 行，字符约为两倍高，看起来等距）；方框正好装下一个图标：12×12 色点即 12×6 字符（与战斗网格一格同尺寸），连边框 14×8。容量内的空位画成更暗的空方框。格子里不另写物品名，与其他游戏的背包一致，物品名在详情区显示；图标未就绪时由物品名（按品质上色、居中折行）代替图标，后台生图未完成时也用这个占位。已装备的物品在方框上边框标 `EQUIPPED`，以后的堆叠数量也标在方框边上。容器只规定列数、行数和标签页（筛选），点击后的行为由所在画面决定；装备位是同尺寸的单个方框。详情区把图标放大两倍显示。
- **创角起始装备（2026-10-21 确认）。** 创角第 4 步，位于通用技能之后、确认之前，分三栏：
  - **左栏：角色（宽 52）。** 名字、等级、HP；属性缩写在上、数值在下排成一行（参考《博德之门 3》）；紧接着是战斗数值卡片（攻击、副手攻击、速度、护甲、盾值、闪避）；然后是有点数的技能，两列表格、先竖后横；最下面是主手、护甲、副手三个装备位，与卡片同一套三列。立绘出来后再调整。确认页（第 5 步）的左栏也用这一栏显示最终角色。
  - **中栏：起始装备（宽 93）。** 5×4 格，标签页 MAIN HAND／ARMOR／OFF HAND 各列出能装进该位置的普通品质物品。点击格子装进当前标签对应的位置，再点已装备的那件卸下；点左栏的装备位切换到对应标签，当前标签的装备位用天蓝框。
  - **右栏：详情（宽 54）。** 显示悬停的物品，没有悬停时显示当前标签已装备的那件；描述跟在特性后面，用分隔线隔开。底部固定位置的 IF EQUIPPED 只列会变的派生数值，如 `Attack 14 (+3)`，变好用绿色、变差用红色，并列出会被换下的装备。BACK／NEXT 在详情下方，主手与护甲都装上之前 NEXT 不可用。
  - **键盘。** 方向键只在格子内移动（到边停住，不绕回）；装备位用 TAB／Shift+TAB 或点击切换，不占键盘焦点；E 装备或卸下，ENTER 下一步，ESC 返回。
- **背包（2026-10-22 确认）。** 从冒险界面工具栏的 Inventory 或 I 键打开，ESC、I 或 CLOSE 关闭。三栏同创角第 4 步：左栏角色（真实玩家），中栏 BACKPACK 5×4 格，右栏详情加 CLOSE。背包格子与身上的装备位都是命令型条目：悬停与键盘共用焦点，单击直接执行；TAB／Shift+TAB 在背包与身上两个区域间切换，方向键在区域内移动，E 与单击相同。单击背包里的装备按 §7.1 默认规则装上，换下的回到背包；单击身上的装备位卸回背包，空位只提示。背包里的装备显示按默认位置比较的 IF EQUIPPED，身上的不比较。装备后从背包移走、不标 E（格子背包＋纸娃娃的做法，参考《博德之门 3》；标 E 属于没有装备位的清单式背包）。暂不做分类标签、分页（超过 20 件时多出的不显示，加战利品时一并做）、拖拽；有使用、丢弃等多种操作的物品出现时，改为对象型（单击选中、按钮执行）。
- **建议特效：**静态人物配短暂的命中变色、伤害数字、斩击弧或光点轨迹，约 0.3–0.5 秒。机械结果只结算一次，动画跳过或失败不重复结算；播放期间暂停输入，不引入多线程。可参考 [JLine Display 差异更新](https://jline.org/docs/advanced/screen-clearing/#using-the-display-class)。
- **顺序。** 创角起始装备 → 背包 → 战斗界面 → 冒险界面的角色／日志抽屉与 NPC 高亮。图片转字符格、后台生图与视觉小说冒险界面放到 v1 之后视进度而定。
